# LaundryKu — Unduhan Aplikasi

Aplikasi kasir & manajemen usaha laundry untuk Android (HP & tablet).

## Unduh versi terbaru

➡️ **[Unduh APK terbaru](../../releases/latest)** — buka bagian *Assets*, lalu pilih file `LaundryKu-vX.Y.Z.apk`.

## Cara memasang / memperbarui

1. Unduh file APK di HP/tablet Android.
2. Buka file tersebut. Jika diminta, izinkan *"Instal aplikasi tidak dikenal"* untuk browser/file manager.
3. Ketuk **Instal** (atau **Perbarui**). Data usaha dan aktivasi tetap aman saat memperbarui.

Aplikasi akan memberi tahu otomatis bila ada versi baru, atau cek manual di **Akun → Cek Pembaruan**.

## Aktivasi

Aplikasi berlisensi. Saat pertama dibuka, kirim **Kode Perangkat** yang tampil ke penjual untuk mendapatkan kode aktivasi.
